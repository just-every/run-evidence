# Brand marks

The approved design (desk README, 16 Oct 2026) asks for the real Rippling and Jamf marks in the
control-test card. These are the symbols from each company's own site logo, unmodified apart from
dropping the wordmark: `rippling.svg` from the header logo on https://www.rippling.com/ and
`jamf.svg` (#056ae6) from the header logo on https://www.jamf.com/ (17 Oct 2026). They name the
integration only and imply no endorsement. Every other third party on the site is plain text.
