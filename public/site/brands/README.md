# Brand marks

The approved designs (desk README, 16 Oct 2026, and the page-s1 structure approved 17 Oct 2026)
draw the real marks of the systems Evidence connects to. Each is the company's own symbol,
unmodified apart from colour where noted. They name the integration only and imply no endorsement.

- `rippling.svg`: the symbol from the header logo on https://www.rippling.com/ (17 Oct 2026).
- `jamf.svg` (#056ae6): the symbol from the header logo on https://www.jamf.com/ (17 Oct 2026).
- `okta.svg`: the sunburst from the header logo on https://www.okta.com/ (20 Oct 2026), filled
  #1662dd as the desk draws it (the site's own file is white on dark).
- `github.svg`, `slack.svg`, `aws.svg`: the GitHub mark, the Slack hash and the AWS logo as
  published by Simple Icons 13.21.0 (CC0 path data); Slack and AWS take their brand colours.
- `pdf.svg`: a page outline around the Adobe Acrobat glyph (Simple Icons 13.21.0), for PDF uploads.

Every other third party on the site is plain text.
