# Fonts

Onest is the shared body and heading face. JetBrains Mono is used for fingerprints,
short codes and reviewer links. Both variable Latin WOFF2 files are self-hosted;
their SIL Open Font License 1.1 texts are beside them in `onest/OFL.txt` and
`jetbrains-mono/OFL.txt`.

Variable WOFF2 distributions: `@fontsource-variable/onest` and
`@fontsource-variable/jetbrains-mono`. Sources: [Onest](https://github.com/google/fonts/tree/main/ofl/onest) and
[JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono).
The theme imports `/fonts/fonts.css`; Base's font head preloads Onest.
