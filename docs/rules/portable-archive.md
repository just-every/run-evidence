# Portable archive bounds

These are the exact rules, bounds and formats behind PORTABLE-001 in [CONTRACT.md](../../CONTRACT.md). The contract holds the requirement and its acceptance; this page holds the mechanism they rely on, as recorded when the contract was rewritten to the RER contract standard on 28 October 2026.

The current v10 format has no total-archive ceiling: archives of any total size stream through bounded record pages, frames and file parts; individual original files retain their public-door size limits.

Proceeding without that journal requires explicit acknowledgement and never claims protection from unknown later erasures.

Status note: Current records and originals conform; named future capabilities inherit archive parity before shipping.
