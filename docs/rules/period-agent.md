# Audit-period investigation rules

These are the exact rules, bounds and formats behind AGENT-002 in [CONTRACT.md](../../CONTRACT.md). The contract holds the requirement and its acceptance; this page holds the mechanism they rely on, as recorded when the contract was rewritten to the RER contract standard on 28 October 2026.

**Current door and exact rules (21 October 2026).** Control → Audit-period report → Ask agent to investigate this period retains a fingerprinted investigation attributed to the requesting owner. Its agent is deterministic source correlation, with no model invocation or external call. It correlates the retained cloud, identity/security and deployment resource versions and observations with captured control/test revisions and historical scope; source-reported data stays source-reported. The period is inclusive UTC days, clipped at the investigation time. Evaluation/receipt times never impersonate a provider event timestamp: original source fields and source references remain inspectable, and absent event coverage stays unknown. Missing observation windows are per resource and start after 1.5 times the cadence in the recorded test revision. Contradictions mean opposite pass/fail results for the same exact resource ID and identical serialized criteria at equal evaluation times or strictly overlapping recorded intervals; differing criteria are not declared contradictory. Scope matches exact resource IDs; unmatched names and unobserved populations remain findings, never inferred identities. Each finding links its immutable observation, source version, scope decision or evaluated definition. Every retained source/observation remains unchanged.

The owner reviews or rejects the exact investigation fingerprint with a reason. Both decisions record only a findings disposition; control meaning and expiring exceptions require their existing separate owner approvals, and the auditor retains the evidence-sufficiency decision. Investigations, decisions and original citations survive restart and custody restore without replay. Work is bounded: a projection or findings list above 5,000 rows, 100,000 comparisons, or an investigation snapshot above 512 KiB is explicitly refused before a proposal is saved; a narrower period can be selected.

The source projections also refuse above 8 MiB.
